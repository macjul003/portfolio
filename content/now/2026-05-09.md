## PollutionTracker v1.0.1: location granularity and UI refresh

Released v1.0.1 of PollutionTracker. The main changes: sub-locality geocoding (now shows "Avadi, Chennai" instead of just "Chennai"), a refresh button in the footer of the popover, and the quit menu item lost its icon (looked inconsistent with the system menu items around it).

Moved the refresh button from wherever it was — context menu probably — into the popover footer. It belongs in the popover, next to the data it refreshes. Context menus are for destructive or rare actions; refresh is a common interaction.

Fixed location reliability using a last-known-location fallback. The original implementation would show no city name if CoreLocation hadn't finished a geocoding lookup by the time the popover opened. Now it caches the most recent successful result and shows that until a fresher one arrives.

Updated the Homebrew Cask to v1.0.1.

## Tria card prototype: autoplay and touch indicator

Added an autoplay loop to the Tria card carousel — cycles Virtual → Signature → Platinum every 1.8 seconds, scrolls down to benefits, then loops every ~9 seconds. Added a touch indicator dot that syncs with the autoplay state to signal that the carousel is interactive. Later simplified the dot to a static fade indicator (the sync animation was overcomplicating a subtle cue).
