## Built JulianLM — an AI chatbot for the portfolio

Added an AI chat panel (JulianLM) that slides in from the right sidebar. Keyword-matched responses at first, giving way to a proper LLM backend later. The name felt right — a personal model that speaks as me, about my work.

Also added the Zomunk case study page with persona cards and stats. Two case studies now live.

## Light/dark theme toggle

Added a theme toggle to the sidebar with a circular view transition animation — the page inverts from the click point outward. Subtle but satisfying. Dark is default; the preference persists in localStorage so it survives page refreshes.

## Design system cleanup

Replaced hardcoded hex colors throughout with `--text-muted` and `--surface` CSS variables. Should have done this earlier — the codebase was accumulating magic values that were impossible to update consistently.

Added lightbox components (LightboxImage, LightboxVideo) to the Symmetry case study, replacing bare `img`/`video` tags. Makes the media feel more intentional and gives the reader a way to inspect details.
