## Started PollutionTracker

Built the first version of PollutionTracker — a macOS menu bar app that shows real-time air quality at a glance. The idea came from wanting to know whether it was worth going outside for a run without pulling up a weather app.

The initial version was a single SwiftUI file: reads AQI from an open API, formats it as a coloured indicator, sits in the menu bar. No popover, no settings — just a number and a colour. Rough but working.

SwiftUI for menu bar apps is more friction than it looks. `MenuBarExtra` is the modern API but it has quirks around popover presentation that AppKit-native NSStatusItem doesn't. Filed it away to deal with later.
